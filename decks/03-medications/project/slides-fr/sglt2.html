Quand l’ACD arrive avec une glycémie normale

Inhibiteurs du SGLT2

Empagliflozine (Jardiance), dapagliflozine (Forxiga), canagliflozine (Invokana).

Des médicaments contre le diabète de type 2, aussi prescrits pour l’insuffisance cardiaque et les maladies rénales — des personnes vivant avec le type 1 finissent donc par en prendre.

Ils évacuent le glucose dans l’urine. Dans le type 1, cela crée un piège précis : vous pouvez faire une acidocétose diabétique complète alors que votre lecteur affiche une glycémie normale. C’est ce qu’on appelle l’ACD euglycémique.

L’alarme sur laquelle vous comptez depuis le diagnostic — un chiffre élevé — ne sonne jamais. Santé Canada et les autres organismes de réglementation ont signalé ce risque précisément.

Si vous en prenez un : des bandelettes pour les cétones, pas seulement la glycémie. Vomissements, mal de ventre ou essoufflement inhabituel : vérifiez les cétones, peu importe le chiffre.

Dans le type 1, l’usage est hors indication presque partout : c’est une décision à prendre avec un ou une spécialiste, avant de commencer — jamais une pilule à essayer parce qu’elle a aidé quelqu’un d’autre.

Si quelqu’un dans la salle en prend déjà un et ne le savait pas, ce sont les trente secondes les plus précieuses de toute la présentation.
