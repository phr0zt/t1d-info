Le corps se souvient aussi des bonnes périodes

Les chercheurs appellent ça la mémoire métabolique. Une période de glycémie proche de la normale continue de rapporter pendant des années — même si les chiffres remontent ensuite.

De quatre à huit ans après l’essai, avec la même A1C dans les deux groupes, le groupe intensif avait encore 72 % moins de progression de l’atteinte des yeux et 84 % moins de nouvelles fuites de protéines rénales.

Et ça marche dans l’autre sens

L’effet s’estompe après une dizaine d’années. Les chercheurs parlent d’amnésie métabolique.

Une année difficile, une adolescence houleuse ou une période où la vie rendait le diabète impossible ne sont donc pas une condamnation. Le corps oublie dans les deux sens.

Source : Understanding Metabolic Memory, Diabetes Care 2021 · EDIC. Dites les deux moitiés — ce n’est jamais « le mal est déjà fait ».

Les personnes qui ont traversé une mauvaise période concluent souvent que leur avenir est déjà joué. Les données sur l’atténuation de l’effet disent le contraire, et c’est la chose la plus utile que vous puissiez leur dire.
